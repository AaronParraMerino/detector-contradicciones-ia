# Detector de Contradicciones IA

Aplicación inteligente para detectar posibles contradicciones en textos mediante Procesamiento de Lenguaje Natural y retroalimentación basada en Aprendizaje por Refuerzo.

## Tecnologías

- Python
- FastAPI
- React
- Tailwind CSS
- Hugging Face Transformers
- SQLite
- GitHub
